# 漫步陆家嘴 - 东方明珠城市探索 (Lujiazui 3D Explorer)

基于 Three.js 构建的 3D 城市漫步与地标探索游戏，支持在陆家嘴街道、广场与滨江区域自由行走、切换视角与时间氛围，并探索东方明珠与陆家嘴天际线。

## 计划包含的核心特性

- **东方明珠与陆家嘴天际线**：东方明珠广播电视塔（斜撑巨柱、下球体、上球体、太空舱、霓虹环），搭配上海中心大厦、环球金融中心、金茂大厦与黄浦江场景。
- **双视角与自由移动**：支持 `W A S D` / 方向键行走、`Shift` 奔跑、`Space` 跳跃、鼠标拖拽环顾，以及第一人称 / 第三人称视角切换。
- **时间氛围与打卡拍照**：支持夜景、黄昏、白昼切换，景点打卡解锁与城市明信片拍照。
