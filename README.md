# 漫步陆家嘴 - 东方明珠 3D 城市探索 (Lujiazui 3D Explorer)

基于 Three.js 构建的 3D 城市漫步与地标探索游戏，可在上海陆家嘴广场、街道与滨江区域自由行走，探索东方明珠广播电视塔与陆家嘴天际线。

## 文件说明

- `index.html`：可直接作为静态网页入口运行（适合 GitHub Pages / Cloudflare Pages 一键托管）。
- `lujiazui_explorer.html`：独立单文件游戏源码。

## 核心玩法与特性

- **东方明珠与陆家嘴天际线**：东方明珠塔（斜撑巨柱、上下球体、太空舱、光环与顶部灯标），搭配上海中心大厦、环球金融中心、金茂大厦、黄浦江游船与外滩剪影。
- **地标打卡与能量球收集**：共设 **7 个打卡地标**（含世纪大道起点、北滨江光影长廊）与 **8 颗陆家嘴探索能量球**，小地图实时显示未收集目标与当前位置。
- **双视角与自由移动**：`W A S D` / 方向键行走、`Shift` 奔跑、`Space` 跳跃、鼠标左键拖拽环顾，支持第一人称与第三人称视角切换。
- **氛围切换与打卡明信片**：支持璀璨夜景、陆家嘴黄昏、晴朗白昼切换，走入发光光柱解锁地标打卡，并可生成带统计信息的打卡明信片。
